# Deployment

## Requirements

- Node.js >= 20.9 (Next.js 16 requirement)

## Commands

```sh
npm install        # install dependencies
npm run dev        # development server
npm run typecheck  # TypeScript check
npm run lint       # ESLint
npm run build      # production build
npm run start      # serve the production build
```

## Environment variables

Both optional. Without them the site deploys and works; the contact form
tells the visitor no delivery mechanism is configured (it never fakes a
successful send) and offers a pre-filled `mailto:` fallback instead.

| Variable | Purpose |
| --- | --- |
| `RHUBARB_ENQUIRY_ENDPOINT` | HTTPS URL that receives contact-form enquiries as a JSON POST (mail function, webhook, CRM inbound URL). See `.env.example` and `src/app/api/enquiry/route.ts`. |
| `RHUBARB_ENQUIRY_TOKEN` | Optional. Sent as `Authorization: Bearer …` to that endpoint when set. |

Set them in Vercel under Project → Settings → Environment Variables. Never
commit real values; `.env*` is gitignored (`.env.example` is the template).

## Vercel notes

- Framework preset: Next.js. No custom build settings needed — `npm run build` / `.next` defaults.
- No remote image domains are used; all images are local under `/public/assets`.
- Fonts are self-hosted via `next/font/local` — no external font requests.
- `AGENTS.md` / `CLAUDE.md` are agent-tooling docs regenerated by `next dev`; committing them is expected.
